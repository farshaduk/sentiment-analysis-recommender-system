LEXICON PACKAGES COMPARISON REPORT
Team #4 – Industrial and Scientific Dataset
================================================================================

1. VADER (Valence Aware Dictionary and Sentiment Reasoner)
------------------------------------------------------------
Strengths:
  • Designed for social-media / informal text (product reviews)
  • Handles CAPITALISATION as emphasis
  • Handles punctuation emphasis (e.g. 'great!!!')
  • Handles degree modifiers ('very', 'extremely')
  • Handles conjunctions & negation ('but', 'not good')
  • Very fast — no heavy NLP pipeline required
  • Provides a compound score that aggregates all cues
Weaknesses:
  • May under-perform on formal / technical text
  • Rule-based — cannot be fine-tuned on domain data

2. TextBlob
------------------------------------------------------------
Strengths:
  • Simple API — polarity + subjectivity in one call
  • Good general-purpose sentiment analyser
  • Subjectivity score can help filter factual reviews
  • Built on Pattern library with proven accuracy
Weaknesses:
  • Less sophisticated handling of informal language
  • No explicit handling of capitalisation / punctuation emphasis

3. SentiWordNet
------------------------------------------------------------
Strengths:
  • Based on WordNet — semantic relationships available
  • Separate positive / negative / objectivity scores
  • Useful for word-level sentiment inspection
Weaknesses:
  • Requires heavy preprocessing (tokenise, POS-tag, lemmatise)
  • Significantly slower than VADER and TextBlob
  • First-synset heuristic may miss correct sense
  • Does not handle negation or degree modifiers

RECOMMENDATION  (selected for model building)
================================================================================

For Amazon product reviews (Industrial & Scientific), we select:

  ★ VADER
    – Product reviews contain informal language, emphasis (!!!),
      capitalisation, and modifiers that VADER is specifically built for.
    – Fastest execution — practical for larger datasets.
    – Requires minimal preprocessing, preserving original text signals.

  ★ TextBlob
    – Provides a reliable second opinion with a different methodology.
    – Subjectivity score adds an extra dimension for analysis.
    – Good balance between accuracy and simplicity.

  ✗ SentiWordNet  (not selected)
    – Requires heavy NLP preprocessing which can remove sentiment cues.
    – Significantly slower — impractical at scale.
    – Word-sense disambiguation (first-synset heuristic) is unreliable
      on informal product reviews.
